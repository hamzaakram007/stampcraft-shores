# Stampcraft Shores

Kids island-building MVP: explore gentle shores → earn transparent stamps → unlock build pieces → decorate your island → tour simulated friend islands and leave stickers (no open chat).

## Run

```bash
npm install
npm run dev
```

## Core loop

1. **Explore** — short tap challenges with fixed stamp rewards (no gacha)
2. **Album** — spend stamps to unlock pieces; costs shown up front
3. **Build** — place unlocked pieces on a 4×4 shore grid
4. **Tour** — visit Mira, Jun, and Aiko’s sample islands; leave one sticker each

Progress saves in `localStorage`.
